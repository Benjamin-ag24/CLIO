# ADR-02: Estilo de Código y Formateo (JavaScript)

**Fecha:** 02/08/2026
**Estado:** Aceptado

## Contexto

El proyecto necesita un estilo de JavaScript claro y uniforme tanto en frontend como en backend.

## Decisión

Se priorizará el uso de módulos ES, imports/exports explícitos, semicolons y nombres de variables en camelCase.

## Alternativas

Mantener un estilo mixto dificultaría la coherencia con Vite y Node moderno.

## Consecuencias

- ✅ Código más fácil de leer y mantener.
- ✅ Mejor compatibilidad con el stack actual de React y Express.
- ⚠️ Requiere disciplina al escribir nuevos archivos y funciones.
