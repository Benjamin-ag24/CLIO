# ADR-04: Framework de Estilos (UI)

**Fecha:** 02/08/2026
**Estado:** Aceptado

## Contexto

La interfaz necesita un sistema de estilos rápido, flexible y consistente que defina la identidad visual de Clio (paleta de colores, sombras, responsive) y permita construir los componentes de forma ágil.

## Decisión

1. **Framework:** Usar **Tailwind CSS** con clases utilitarias directamente en JSX.
2. **Paleta de colores:** Celeste (`#7fb3d1`), café (`#5b3f2d`) y beige (`#f7f2ec`) definidos como valores arbitrarios.
3. **Sombra:** Las tarjetas usan una sombra sutil definida con valores arbitrarios.
4. **Responsive:** La interfaz se adapta usando prefijos de Tailwind (`sm:`, `md:`, `xl:`).

## Alternativas

Usar CSS puro o una librería de componentes completa, lo cual sería más pesado para este proyecto.

## Consecuencias

- ✅ Desarrollo más ágil para la UI.
- ✅ Estilos consistentes y fáciles de ajustar.
- ⚠️ El JSX puede volverse más largo por el uso de muchas clases.
