# ADR-01: Estructura y Nomenclatura de Componentes en React

**Fecha:** 02/08/2026
**Estado:** Aceptado

## Contexto

Necesitamos consistencia en el nombre de componentes y archivos para que la app sea fácil de navegar.

## Decisión

Se usarán archivos con nombres en camelCase y componentes con nombres en PascalCase, como Home, Header y ReportPanel, siguiendo la estructura actual del frontend.

## Alternativas

Usar nombres inconsistentes o mezclar convenciones entre páginas y componentes.

## Consecuencias

- ✅ Código más legible y predecible.
- ✅ Más sencillo localizar vistas, paneles y componentes reutilizables.
- ⚠️ Requiere mantener la convención de forma consistente.
